# Security policy

## Reporting a vulnerability

Please do not disclose vulnerabilities, credentials, or reproduction details in
public issues or pull requests. Use GitHub's private vulnerability reporting:

[Report a vulnerability privately](https://github.com/skiweg1985/prtg-nats/security/advisories/new)

Include the affected version or commit, prerequisites, impact, and a minimal
reproduction. Do not include production credentials or personal data.

## Maintainer audit tracking

Authorised maintainers track audits and remediation in the
[private security-audits repository](https://github.com/skiweg1985/security-audits).
Audit reports and findings are organised by source repository and audited commit.
Access requires explicit GitHub permission; this link does not grant access.
People without access may receive a 404 response. Use the private reporting
channel above to submit a new vulnerability instead of requesting tracker access.

Private finding details must not be copied into public issues, commits, or pull
requests before coordinated disclosure has been approved.
